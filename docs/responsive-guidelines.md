# 响应式布局规范

## 断点策略

- 采用 Tailwind mobile-first 方式。
- 基础样式先覆盖 `<640px`。
- 再按 `sm`、`md`、`lg` 逐步增强。

## 统一约束

- 默认避免水平滚动，优先让布局折叠、换行、分步展示。
- 面板之间留白统一从小屏的 `gap-3/gap-4` 起步，桌面再扩到 `gap-5/gap-6`。
- 表单、Popup、Spotlight、Sticky 的主要操作按钮在小视口必须首屏可见。
- 中宽度先压缩侧栏和详情宽度，再考虑隐藏次级说明文案。
- 大屏保留三段式工作台，但任何区域最小宽度都不能让文本输入失去可用性。

## 组件级规则

- 主窗口：
  - `<md` 使用单列或分步展示。
  - `md-lg` 允许侧栏收缩、详情后置。
  - `lg+` 才使用完整桌面工作台。
- Overlay / Spotlight：
  - 小视口限制最大宽度和结果区高度。
  - 操作区必要时换成两列或单列。
- Sticky：
  - 默认尺寸偏小，文本强制换行。
  - 折叠态和窄屏下优先保证拖拽与关闭操作。

## 开发要求

- 新组件提交前至少检查四档宽度：`<640`、`640-767`、`768-1023`、`>=1024`。
- 新增布局时优先复用现有容器宽度和圆角节奏，不单独发明断点策略。
